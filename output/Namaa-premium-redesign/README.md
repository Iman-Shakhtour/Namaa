# نماء — الموقع التعريفي

موقع عربي RTL لنظام نماء، مبني على HTML وCSS وVanilla JavaScript دون خطوة build أو مكتبات واجهة ثقيلة.

## التشغيل المحلي

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8765/`.

## النظام البصري

- هوية Finance SaaS بألوان Navy وEmerald وMint ومساحات بيضاء هادئة.
- Hero داكن مع فيديوين WebM مصنوعين من شاشات نماء الأصلية فقط: نسخة أفقية للكمبيوتر ونسخة عمودية للهاتف.
- Bento للمميزات، وProduct Story ثابت على الكمبيوتر يتحول إلى بطاقات متتابعة على الهاتف.
- أقسام مستقلة للأوفلاين والتقارير والصلاحيات والبيئة الخاصة والتخصيص والأجهزة.
- احترام `prefers-reduced-motion`: يتوقف الفيديو وتظهر صورة المنتج البديلة.

## المحتوى والأصول

شاشات نماء الأصلية والمحاصيل المشتقة منها في `assets/screenshots/`. لا توجد واجهات مولدة أو رسوم بيانية جديدة. صورة الصلاحيات العامة تحجب أسماء الدخول فقط، وتبقي الأدوار ظاهرة.

فيديو المنتج في `assets/media/` مُنشأ من لقطات نماء الموجودة في المشروع بحركة تكبير وانتقالات هادئة. الصور والفيديوهات تستخدم أبعادًا معلنة، والصور غير الفورية محملة كسولًا.

منتجات Logix المعتمدة في `js/hardware-data.js`. يعرض الموقع أربعة منتجات مرتبطة بنقطة البيع فقط. سعر Xprinter مخفي حتى اعتماد الإدارة، ودرج النقد غير معروض.

خطط الاشتراك وأسعارها محفوظة دون تغيير. إعدادات التواصل في `js/site-config.js` وتظل فارغة، لذلك لا يظهر واتساب. فيديوهات الشرح في `js/tutorials-data.js`؛ إذا بقيت القائمة فارغة فلا يظهر القسم.

## عناصر تنتظر الاعتماد

- رقم واتساب وروابط التواصل الرسمية.
- سعر ونسخة Xprinter النهائية.
- منتج وسعر درج النقد.
- مراجعة الإدارة لخطط الاشتراك الحالية.
- فيديوهات الشروحات.
- لقطات مستقلة لحالات الأوفلاين وانتظار المزامنة ونجاحها.

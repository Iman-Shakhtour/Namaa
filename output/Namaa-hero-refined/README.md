# نماء — الموقع التعريفي

موقع عربي متجاوب مبني على HTML وCSS وVanilla JavaScript. تم تعديل المشروع الموجود محليًا دون تغيير التقنية أو النشر.

للمراجعة، افتح `index.html`، أو شغّل من هذا المجلد:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8765/`. لا توجد خطوة build أو إعداد lint في المشروع.

إعدادات التواصل في `js/site-config.js`. أضف رقم واتساب الدولي بالأرقام فقط وروابط إنستغرام وفيسبوك المعتمدة. القيم الفارغة أو غير الصالحة لا تظهر للزائر؛ وتبقى الأزرار تقود إلى عرض البرنامج. عند إضافة بيانات صالحة، تتحول أزرار التواصل تلقائيًا بعد تحديث الصفحة.

منتجات Logix وصورها المحلية وأسعارها ومصادرها في `js/hardware-data.js`. تظهر المنتجات المعتمدة فقط، ويظهر السعر فقط عند `approvedPrice: true`. أربع بطاقات مختصرة وقائمة خيارات قابلة للفتح. سعر Xprinter مخفي حتى اعتماد الإدارة، ودرج النقد غير معروض. بيانات خطط الاشتراك الحالية محفوظة كما كانت، إلى حين تحديث الإدارة.

تحديث الأوفلاين المعتمد: يبدأ المستخدم بتسجيل الدخول وعملية بيع أونلاين، ثم يمكنه مواصلة البيع من فاتورة البيع وPOS النقدي عند الانقطاع. العمليات محفوظة محليًا؛ تُراجع المزامنة أعلى النظام، ويمكن إعادة المحاولة بالسهم عند تعذرها. لا يوجد ادعاء بأن كل النظام يعمل دون اتصال.

بيانات الشروحات في `js/tutorials-data.js`. أضف الفيديوهات المعتمدة بالشكل `{ id, title, description, url }`، مع رابط HTTPS. إذا كانت القائمة فارغة أو الروابط غير صالحة، لا يُدرج قسم «شروحات نماء». لا توجد فيديوهات بديلة أو مؤقتة.

الشاشات الحقيقية داخل `assets/screenshots/` بصيغة WebP. صورة الصلاحيات تحجب أسماء الدخول فقط. الصور لا تُقص داخل الموقع ولا تُمدد، ويمكن تكبيرها أو فتحها بالحجم الأصلي. الصور الأصلية غير المعدلة ولقطات الموقع ونتائج الفحص مرفقة في مجلد `Review` داخل ZIP التسليم، خارج مجلد الموقع. احتفظ بمجلد المراجعة محليًا؛ صورة الصلاحيات الأصلية تتضمن أسماء الدخول.

الخط Tajawal يُحمّل من Google Fonts مع `display=swap` وخطوط احتياطية. يبقى المحتوى والتنقل متاحين إذا تعذر تحميل الخط.

المطلوب لاحقًا: رقم واتساب وروابط التواصل، اعتماد منتج وسعر Xprinter، اعتماد درج النقد، تحديث خطط الاشتراك، سياسة رسمية لنطاق التخصيص المجاني، الفيديوهات المعتمدة، وصور حالات انقطاع الاتصال وانتظار المزامنة ونجاحها.

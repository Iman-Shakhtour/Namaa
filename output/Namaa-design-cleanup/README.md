# نماء — الموقع التعريفي

موقع عربي RTL لنظام نماء، مبني بـ HTML وCSS وVanilla JavaScript دون خطوة build أو مكتبات واجهة ثقيلة.

## التشغيل المحلي

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8765/`.

## النظام البصري

- لوحة ألوان واحدة: `#07182F` و`#0D9368` و`#12B886` و`#E7F4EF` و`#F7F8F6` و`#FFFFFF` و`#101828` و`#667085` و`#E2E8E5`.
- حاوية موحدة بعرض أقصى `1200px` وحشو جانبي `clamp(18px, 4vw, 32px)`.
- زوايا موحدة: `12px` للأزرار، `16px` للعناصر الصغيرة، و`20px` للبطاقات ولقطات المنتج.
- Hero داكن ومدمج يعرض فيديو مبني من شاشات نماء الفعلية، مع نسخة أفقية للحاسوب وعمودية للهاتف.
- خمس بطاقات ميزات بنظام موحد، ثم محدد نصي واحد وصورة نشطة على الحاسوب وبطاقات متتابعة على الهاتف.
- أقسام الأوفلاين والتقارير والصلاحيات والبيئة والأجهزة والأسعار والأسئلة متناسقة مع النظام نفسه.

## الأصول والسلوك

- شاشات نماء الأصلية والمحاصيل منها موجودة في `assets/screenshots/`، دون واجهات مزيفة أو مخططات مخترعة.
- فيديوهات المنتج في `assets/media/` مصنوعة من الشاشات الأصلية فقط.
- صور الأجهزة في `assets/hardware/` وبياناتها المعتمدة في `js/hardware-data.js`؛ يظهر ثلاثة منتجات كحد أقصى، ولا يظهر سعر Xprinter قبل اعتماده.
- إعدادات التواصل في `js/site-config.js`، والشروحات في `js/tutorials-data.js`. لا يظهر قسم أو رابط بلا بيانات معتمدة.
- القائمة الهاتفية تقفل تمرير الصفحة أثناء فتحها، وتدعم Escape. عارض الصور والأسئلة الشائعة يدعمان لوحة المفاتيح.
- يحترم الموقع `prefers-reduced-motion` ويعرض صورة بديلة عند إيقاف الحركة.

## التحقق

تم فحص المقاسات 320 و360 و390 و430 و768 و1024 و1440 بكسل. نتائج المقاسات والتفاعلات ولقطات الصفحة الكاملة موجودة في `output/design-cleanup-review/`.

## عناصر تنتظر الاعتماد

- رقم واتساب وروابط التواصل الرسمية.
- سعر ونسخة Xprinter النهائية.
- منتج وسعر درج النقد.
- مراجعة الإدارة لخطط الاشتراك الحالية.
- فيديوهات الشروحات.
- لقطات مستقلة لحالات الأوفلاين وانتظار المزامنة ونجاحها.
